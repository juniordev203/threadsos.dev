## 1. Mục tiêu & Scope

### Mục tiêu
Xây dựng giao diện Trình soạn thảo chính (Main Editor Page) theo bố cục Split-screen (50/50 desktop, 1 column mobile stack), bao gồm Editor Input Panel (nơi nhập ý tưởng & chọn framework), Threads Post Card (card preview chuẩn Threads) và Editor Preview Panel (nơi xem trước, copy, viết lại, chỉnh sửa).

### In-Scope
1. **`app/components/editor/EditorInputPanel.vue`**:
   - Framework Badge Selector: chọn framework slug (`unpopular_opinion`, `lesson_learned`, `how_to`, `tool_stack`, `before_after`, `myth_busting`, `personal_story`).
   - Textarea nhập ý tưởng với Geist font, min-height 200px, character counter (JetBrains Mono 12px) góc dưới phải.
   - Section "💡 CÂU HỎI KÍCH THÍCH Ý TƯỞNG" chứa 3 static suggestion card ("Dùng câu này →").
   - Button "Generate Thread ⚡" (48px, primary style, `.card-hover`).
   - Emit event `@generate`, `@select-framework`, `@update:modelValue`.

2. **`app/components/editor/ThreadsPostCard.vue`**:
   - Component hiển thị bài viết chuẩn Threads.
   - Props: `content` (string), `username` (string, default '@creator'), `timestamp` (string, default 'Vừa xong').
   - Avatar circle 40px với initials/icon.
   - Content preserve line breaks (`whitespace-pre-wrap`, `text-sm leading-relaxed`).
   - Action bar phía dưới với 4 icon Unicode (♡ 💬 ⟳ 🔖).

3. **`app/components/editor/EditorPreviewPanel.vue`**:
   - Panel xem trước bài viết bên phải split-screen.
   - Props: `content` (string), `isLoading` (boolean).
   - Empty state (khi chưa tạo bài): icon ◇, "Bài viết của bạn sẽ xuất hiện ở đây", "Nhập ý tưởng và bấm Generate".
   - Loading state: pulse/skeleton animation.
   - Content state: hiển thị `ThreadsPostCard` kèm toolbar 3 nút: "📋 Copy", "🔄 Viết lại", "✏️ Chỉnh sửa".

4. **`app/pages/app/generate.vue`**:
   - Overwrite trang editor chính với bố cục split-screen.
   - Flexible container, desktop 2 columns (`lg:grid-cols-2`), mobile 1 column.
   - Integrated state cho `inputText`, `generatedContent`, `isGenerating`, `selectedFramework`.
   - Mock generation handler.
