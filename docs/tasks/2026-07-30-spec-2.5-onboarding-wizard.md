## 1. Mục tiêu & Scope

### Mục tiêu
Xây dựng trang Onboarding Wizard 3 bước cho ứng dụng Threads OS bao gồm chọn Lĩnh vực (Niche), Mô tả bản thân (Bio), và chọn Giọng văn (Tone).

### In-Scope
- `app/components/onboarding/OnboardingNiche.vue`: Step 1 - Grid 8 niche options (Technology, Marketing, Design, Business, Freelance, Startup, Education, Other).
- `app/components/onboarding/OnboardingBio.vue`: Step 2 - Textarea 3 rows + info box gợi ý AI.
- `app/components/onboarding/OnboardingTone.vue`: Step 3 - Grid 4 tone cards (Practical, Friendly, Analytical, Storytelling) với checkmark selection.
- `app/pages/onboarding.vue`: Main onboarding wizard page với progress bar 2px, step indicator, dynamic titles, bottom navigation buttons, validation, và routing tới `/app/generate`.

### Out-of-Scope
- Persistence state trực tiếp vào database Supabase (được xử lý ở các task sau).
